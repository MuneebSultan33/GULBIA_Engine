# GULBIA 🧬
### Genomic Utility for Liver Biomarker and Immunotherapy Analysis

GULBIA is a high-throughput clinical bioinformatics engine designed to bridge the gap between raw tumor sequencing (MAF/VCF) and personalized mRNA vaccine design.

## 🚀 Key Features
* **Massive Batch Processing:** Analyzes 50,000+ genomic variants in seconds using asynchronous Python.
* **Neoantigen Discovery:** Predicts MHC-I binding affinity (IC50) for mutant 9-mer peptides.
* **Vaccine Blueprinting:** Automatically assembles multi-epitope constructs with adjuvants and rigid linkers.
* **Aseptic UI:** Enterprise-grade dashboard designed for clinical oncology environments.

## 🛠️ Technology Stack
* **Frontend:** React.js (Hooks, Functional Components, CSS3 Animations)
* **Backend:** Python 3.10, FastAPI, Uvicorn (Asynchronous Concurrency)
* **Algorithms:** Custom Peptide Translation & Binding Affinity Simulation
